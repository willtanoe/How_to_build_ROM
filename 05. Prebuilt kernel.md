# 05. Prebuilt Kernel

## Kernel Source

This guide uses the shared SM6150/SM7150 kernel from crDroid, which supports courbet:

```
https://github.com/crdroidandroid/android_kernel_xiaomi_sm6150
```

> This is a unified kernel for all Xiaomi SM6150/SM7150 devices (including courbet).
> Fork this repo into your GitHub before cloning.

---

## 0. Reference Kernel Tree

For reference, the original guide uses this tree as an example:

```
https://github.com/LeCmnGend/kernel_xiaomi_ginkgo/tree/super-R
```

The structure and build script approach is the same -- only the repo and image file differ.

---

## 1. Edit Build Script

Each kernel repo usually has its own build script (`.sh` file). Open yours and add this function:

```bash
function create_prebuilt {
    # Copy kernel image and dtbo to prebuilt folder
    mkdir -p prebuilt
    cp out/arch/arm64/boot/Image prebuilt/
    cp out/arch/arm64/boot/dtbo.img prebuilt/
    rm -rf out
    make clean
}
```

Then call `create_prebuilt` at the end of your build script, after the kernel compiles successfully.

> Note: courbet uses a plain `Image` file, **not** `Image.gz-dtb` like ginkgo.
> Using the wrong filename here will cause the ROM build to fail when it looks for the prebuilt.

---

## 2. Run Build Script

Run your build script to compile the kernel and generate the prebuilt files:

```bash
bash <your-build-script>.sh
```

Your prebuilt kernel files will be in:

```
kernel/xiaomi/sm6150/prebuilt/Image
kernel/xiaomi/sm6150/prebuilt/dtbo.img
```

Flash and test the kernel on your device before using it in a ROM build.
