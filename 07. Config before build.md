## 0. Check if your WSL2 setup is fine

Run these to verify your environment is ready before doing anything else:

```bash
java --version
javac --version
ccache -v
sdkmanager --list
whereis opt
opt --version
whereis llvm-nm
llvm-nm --version
```

Expected results:

- `java` and `javac` should show version 11
- `ccache -v` should show ccache version info
- `sdkmanager --list` should show a list of SDK packages
- `opt --version` and `llvm-nm --version` should both report LLVM 13.0

If `opt` shows a path outside of `.../proton/clang-13`, remove the system one:

```bash
rm -f /usr/local/bin/opt
```

If any command returns "unknown command" or "not found", see the **Error** folder.

## 2. Config Device Source

Device source is located at:

```
/root/super/device/xiaomi/courbet
```

Use **Windows Explorer** via the **Z drive** you mapped earlier to access files easily.

### 2.1 AndroidProducts.mk

Edit to match your ROM name and device codename:

```makefile
PRODUCT_MAKEFILES := \
    $(LOCAL_DIR)/superior_courbet.mk

COMMON_LUNCH_CHOICES := \
    superior_courbet-user \
    superior_courbet-userdebug \
    superior_courbet-eng
```

### 2.2 `superior_courbet.mk`

Rename the product makefile to match your ROM and device, then verify `PRODUCT_NAME` is correct:

```makefile
PRODUCT_NAME := superior_courbet
```

### 2.3 BoardConfig.mk

Add these flags near the top, below `DEVICE_PATH`:

```makefile
# Temp fixes
BUILD_BROKEN_DUP_RULES := true
ALLOW_MISSING_DEPENDENCIES := true
TEMPORARY_DISABLE_PATH_RESTRICTIONS := true
```

Verify the kernel section has these values. courbet uses kernel 4.19 and outputs a plain `Image` (no gz, no dtb appended):

```makefile
TARGET_KERNEL_VERSION := 4.19
TARGET_KERNEL_SOURCE := kernel/xiaomi/courbet
TARGET_KERNEL_CONFIG := courbet_defconfig
BOARD_KERNEL_IMAGE_NAME := Image
BOARD_KERNEL_SEPARATED_DTBO := true
BOARD_KERNEL_PAGESIZE := 4096
BOARD_KERNEL_BASE := 0x00000000
```

Then append the prebuilt kernel block at the bottom of `BoardConfig.mk`:

```makefile
# Prebuilt kernel
ifneq "$(wildcard $(TARGET_KERNEL_SOURCE)/prebuilt )" ""
TARGET_FORCE_PREBUILT_KERNEL := true
TARGET_PREBUILT_KERNEL := $(TARGET_KERNEL_SOURCE)/prebuilt/Image
BOARD_PREBUILT_DTBOIMAGE := $(TARGET_KERNEL_SOURCE)/prebuilt/dtbo.img
endif
```

> Note: courbet uses a plain `Image` file, not `Image.gz-dtb`. Using the wrong image name will cause a build failure. Always check your kernel source `arch/arm64/boot/` to confirm what gets output.

## 3. Config Kernel Source

Kernel source is located at:

```
/root/super/kernel/xiaomi/courbet
```

Official kernel source (Android 11): [courbet-r-oss](https://github.com/MiCode/Xiaomi_Kernel_OpenSource/tree/courbet-r-oss)

### 3.1 (Optional) Build Standalone Kernel

Configure `b15.sh` to match your kernel folder, then run:

```bash
bash b15.sh
```

Your kernel zip should appear in the kernel folder. Flash and test it on your device before distributing to others.
