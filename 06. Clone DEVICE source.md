## 1. Find Your Device Source

Some ROMs include device support directly in their GitHub org. For example, crDroid has courbet officially:

```
https://github.com/crdroidandroid/android_device_xiaomi_courbet
```

For **SuperiorOS**, the ROM source and device source are separate:

- ROM source: https://github.com/SuperiorOS
- Device source: https://github.com/SuperiorOS-Devices

> courbet does **not** have official support in SuperiorOS-Devices, so you need to find a device tree from another source and adapt it.

---

## 2. Find Device Source Without Official ROM Support

Search Google for `courbet device tree github` or `android_device_xiaomi_courbet`.

Good links look like:

```
https://github.com/<dev>/android_device_xiaomi_courbet
https://github.com/<dev>/device_xiaomi_courbet
```

### Recommended sources for courbet:

| Repo | Notes |
| :--- | :--- |
| [xiaomi-sm6150/android_device_xiaomi_courbet](https://github.com/xiaomi-sm6150/android_device_xiaomi_courbet) | SM6150/SM7150 focused org, actively maintained |
| [crdroidandroid/android_device_xiaomi_courbet](https://github.com/crdroidandroid/android_device_xiaomi_courbet) | Official crDroid tree, well maintained |
| [abdalrahmaneissa/android_device_xiaomi_courbet](https://github.com/abdalrahmaneissa/android_device_xiaomi_courbet) | LineageOS-based tree |

Pick the most actively maintained one (check commit dates). Fork it into your own GitHub, then rename it.

To rename: go to your forked repo on GitHub, click **Settings**, and rename to match this format:

```
device_xiaomi_courbet
vendor_xiaomi_courbet
```

For kernel, fork this shared SM6150/SM7150 kernel repo:

```
https://github.com/crdroidandroid/android_kernel_xiaomi_sm6150
```

Rename your fork to:

```
kernel_xiaomi_sm6150
```

So your links become:

```
https://github.com/<your-gh>/device_xiaomi_courbet
https://github.com/<your-gh>/kernel_xiaomi_sm6150
https://github.com/<your-gh>/vendor_xiaomi_courbet
```

## 3. Clone Device Source

Your ROM source has 3 folders to place device code:

```
/root/super/device
/root/super/kernel
/root/super/vendor
```

### 3.1 Clone device, kernel, and vendor

```bash
git clone -b (branch-name) --single-branch --depth=1 \
  https://github.com/<your-gh>/device_xiaomi_courbet.git \
  ~/super/device/xiaomi/courbet

git clone -b (branch-name) --single-branch --depth=1 \
  https://github.com/<your-gh>/kernel_xiaomi_sm6150.git \
  ~/super/kernel/xiaomi/sm6150

git clone -b (branch-name) --single-branch --depth=1 \
  https://github.com/<your-gh>/vendor_xiaomi_courbet.git \
  ~/super/vendor/xiaomi/courbet
```

> Note the kernel clones to `kernel/xiaomi/sm6150`, not `kernel/xiaomi/courbet`.
> This is because the kernel is shared across all SM6150/SM7150 devices, not courbet-specific.
> `-b 11.0` assumes the branch name -- check your forked repo for the correct branch name first.
> `--depth=1` only downloads the latest commit, saving significant time and disk space.

### 3.2 Verify

Check that all 3 folders exist and are not empty:

```bash
ls ~/super/device/xiaomi/courbet
ls ~/super/kernel/xiaomi/sm6150
ls ~/super/vendor/xiaomi/courbet
```

All 3 should show files. If any is empty or missing, re-run that specific clone command.
